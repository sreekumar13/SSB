# Comparison Report

The report shows how the number of households has increased for each household type over the 19 years observed (2006-2024), and if the median after-tax income in constant price has kept pace with the growth.

So if a household type has the highest rank in number of household growth (which is 1), and the highest rank in the income (which is also 1), then the gap is 0, which might show that the growth in the household number is sustainable.

However for another household has higher rank in number of household growth say for eg: 4 and has a lower rank in income growth say for eg: 10. Then the gap is -6 which shows that the growth in household numbers may not be sustainable.
