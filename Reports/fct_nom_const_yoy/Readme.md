# Comparison Report

The report compares how inflation has affected each of the 15 household group types.

The comparison shows the rate of difference between for after-tax income in nominal and constant terms and how it has changed for each household group over the observed period of 19 years (2006-2024).

Each rate in the report is YOY growth from the previous year, and a higher number means the after-tax income was faring better against inflation numbers.
